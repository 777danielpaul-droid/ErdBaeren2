## ✨ Key Features

### 🌌 **Immersive 3D Space Environment**
Real-time WebGL-rendered cosmos powered by Three.js and React Three Fiber, featuring procedurally animated Milky Way backgrounds and volumetric cloud effects.

### 📖 **Narrative Scroll Progression**
Timeline-driven animations with phased storytelling — each scroll triggers cinematic reveals through a custom TimelineProvider context system.

### 🌙 **Procedural Moon Renderer**
Canvas-based moon generation with realistic crater physics, gradient lighting, and device-pixel-ratio optimization for retina displays.

### 🎨 **Cinematic UI/UX Design**
Dark-themed interface with Noto Sans Runic and Space Grotesk typography, featuring smooth scroll-linked animations and particle effects.

---

## 🏗️ Architecture & Workflow

Built with a **modern React + Three.js architecture** using Vite as the build tool. Features a layered component system:

- **SpaceStage**: WebGL-rendered cosmic background with Three.js
- **MoonLayer**: Canvas-procedural moon generation with gradient lighting
- **CloudVolume**: Atmospheric volumetric cloud effects
- **TimelineProvider**: Custom animation orchestration system
- **ScrollFX**: Framer Motion-powered scroll-linked animations

The app follows a **component-driven development pattern** with strict separation between 3D rendering, 2D canvas effects, and React UI components.
